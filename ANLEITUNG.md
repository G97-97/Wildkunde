# Wildkunde Salzburg: Installation am Handy

Die App ist eine „Web-App“ (PWA). Sie muss **einmal** über eine https-Adresse geöffnet werden, danach liegt sie am Startbildschirm und läuft ohne Internet.

## 1. Online stellen (einmalig)

**GitHub Pages (empfohlen, kostenlos):**
1. Auf github.com ein neues, öffentliches Repository anlegen, z. B. `wildkunde`.
2. Alle Dateien aus diesem Ordner hochladen („Add file“ → „Upload files“).
3. Settings → Pages → Branch `main`, Ordner `/ (root)` → Save.
4. Nach etwa 1 Minute ist die App unter `https://<dein-name>.github.io/wildkunde/` erreichbar.

(Claude kann Schritt 2 und 3 übernehmen, sobald das leere Repository existiert.)

## 2. Auf den Startbildschirm legen

**iPhone (Safari):** Adresse öffnen → Teilen-Symbol (Quadrat mit Pfeil) → „Zum Home-Bildschirm“ → Hinzufügen.

**Android (Chrome):** Adresse öffnen → Menü ⋮ → „App installieren“ bzw. „Zum Startbildschirm hinzufügen“.

Danach die App einmal vom Startbildschirm öffnen, solange noch Internet da ist. Ab dann funktioniert sie offline.

## 3. Updates
Wenn neue Daten dazukommen, lädt die App sie beim nächsten Öffnen mit Internet automatisch.
